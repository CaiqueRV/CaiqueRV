## Projetos em destaque

### Monitoramento de Fluxo de Água com ESP32

**[Acessar repositório no GitHub](https://github.com/CaiqueRV/Monitoramento-Fluxo-de-Agua-ESP32)** · **[Visualizar simulação no Wokwi](https://wokwi.com/projects/476706772789091329)**

Protótipo de monitoramento fluvial desenvolvido com ESP32, com o objetivo de acompanhar o nível da água e a vazão. O sistema integra sensores de medição, um display OLED para apresentação dos dados e LEDs para indicação visual do estado do nível monitorado.

**Tecnologias e componentes:** C/C++, ESP32, JSN-SR04M-2, YF-S201, display OLED SSD1306 e PlatformIO.

O projeto envolve programação de microcontroladores, integração de sensores, aquisição de dados e desenvolvimento de um protótipo físico com simulação complementar.
